  • st

    Stockage

    Inventory for cafes and restaurants.

    Features
    • Items and units — Pack sizes, par levels and reorder points.
    • Recipes and modifiers — Drink sizes, milk swaps and packaging worked out for you.
    • Sales import — Build your menu from a POS export. Toast and generic CSV.
    • Stock ledger — Every sale, delivery, waste and count is a recorded entry.
    • Purchase orders — Drafted from vendor prices, with partial receiving.
    • Printable POs — Your logo and ship-to address. Save as PDF to send.
    • Suggest from par — Fills an order with whatever is running low.
    • Vendors — Price lists, price history and CSV import.
    • Waste log — Reason codes, plus an offline form for employees.
    • Cycle counts — Count, then adjust the discrepancy.
    • Reports — COGS, waste, days of stock, drink margins, usage trends.
    • Backup — Export everything as JSON.

  • mu

    Muster

    Screenwriting software.

    Features
    • Page View — Paper pages in industry-standard format.
    • Type View — The caret stays put and the script moves around it.
    • Metas — Tags that cross documents. Save The Cat and other structure frameworks built in.
    • Drafts — Version Up with change logs. Open notes carry forward.
    • Folders and search — Find any line in any draft, with filters.
    • Scraps — Send a selection to a scrap and keep writing.
    • Proofreading — Spelling, grammar and a walkthrough.
    • Review files — Send a draft as one HTML file for notes, and file the notes back.
    • Import — Final Draft (.fdx) and Fade In.
    • Export — PDF, plus its own .mstr format.
    • Private — No accounts, no cloud, no network calls.
    Recent changes

    0.2.1 — Oct 7

    • Folders open on a click, with a path along the top of the Drafts pane. Anything you make while a folder is open is filed in it.
    • Search across every draft, with filters for scripts, documents, beat sheets, scraps and locked drafts.
    • Send to Scraps: turn a selection into a scrap without leaving the page.
    • Hover a draft to see its change log and how far it has moved from the draft it came from.

    Hey, Someday

    • Rules — Cut spending, pay extra, skip a payment, sell an asset.

  • nl

    The Nice List

    A gift tracking application for the winter holidays.

    Read more

    A gift exchange has exactly one secret: who is buying what. The Nice List keeps it in the database rather than the interface, so no screen, number or notification can give it away.

    • Everyone in a tree keeps a list of what they want.
    • Others claim items on it. Nothing you can see is computed from your own gifts.
    • The secret ends when the recipient says it does, never on a date. Families open presents on Christmas Eve, on Christmas morning, or the weekend after, and any fixed date spoils somebody.
    • Vote each other naughty or nice.
    • Notifications never carry a claimer’s name to the person getting the gift.

    Next year, the tree becomes a party: you pick a monster, it arrives at the tree with everybody else’s, and the tree collects ornaments as the family adds gifts and votes.

    TypeScript · React Native · Supabase · iOS, Android · Backend built, app in progress
